# OCS302. Missing platform param in page opening contexts of tests parametrized with platforms 
Platform param must be used in a page opening context if a test is parametrized and the platform is one of the params
### ❌ Anti-pattern
****
```python
class Scenario(vedro.Scenario):
    subject = "Open some page {platform}"

    @params(Platforms.DESKTOP)
    @params(Platforms.MOBILE)
    def __init__(self, platform):
        self.platform = platform

    def when_open_page(self):
        self.page = await opened_page()
```

### ✅ Best practice

```python
class Scenario(vedro.Scenario):
    subject = "Open some page {platform}"

    @params(Platforms.DESKTOP)
    @params(Platforms.MOBILE)
    def __init__(self, platform):
        self.platform = platform

    def when_open_page(self):
        self.page = await opened_page(platform=self.platform)
```
